COMO GERAR O APK NUM COMPUTADOR COM ANDROID STUDIO
Requisitos: Node.js LTS, Android Studio com Android SDK, e JDK compatível com a versão do Android Gradle Plugin.

1. Extraia este ZIP.
2. Abra um terminal dentro da pasta anime_word_android.
3. Execute: npm install
4. Execute: npx cap add android
5. Execute: npx cap sync android
6. Execute: npx cap open android
7. No Android Studio, aguarde a sincronização do Gradle e escolha Build > Build Bundle(s) / APK(s) > Build APK(s).
8. O Android Studio indicará onde guardou o APK gerado.

NOTA
A primeira compilação pode exigir internet para descarregar dependências. Teste a aplicação no seu dispositivo antes de distribuir. Antes de publicar, confirme direitos de uso das imagens/personagens de anime.
